# iallinone launcher — wydania

To repozytorium udostępnia instalatory Windows, pakiety Linux i manifest automatycznych aktualizacji. Kod źródłowy launchera jest przechowywany w osobnym prywatnym repozytorium.

Pobierz najnowszą wersję w zakładce [Releases](https://github.com/noterago/iallinone-launcher-updates/releases/latest). Po zainstalowaniu wersji 0.6.0 lub nowszej launcher sam sprawdza, pobiera i instaluje podpisane aktualizacje. Nie wymaga tokenu ani konta GitHub.

Wersje 0.5.0 i starsze wymagają jednorazowej ręcznej instalacji 0.6.0, aby przejść na publiczny kanał aktualizacji.
